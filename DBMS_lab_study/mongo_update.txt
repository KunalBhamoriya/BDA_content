--------Indexes
Indexes are used to search the data very fast, 
by storing keys and its position in sorted order
types of indexes:
1. simple index----if the key is single key, then it is 
                   simple index
	 db.movie.createIndex({rating:1}) 
				   
2. compound index---> If the index is based on multiple 
                   keys, then it is compound index
				   
	db.movie.createIndex({rating:1,name:-1})
	
3. composite index---> If the index is based on nested key,
        then it is composite index.
address:{zipcode:33333}    

db.restaurent.createIndex({'address.zipcode':1})

to create index 
db.movie.createIndex({rating:1})
db.movie.createIndex({rating:1,name:1})

to see th list of indexes
db.movie.getIndexes()

to delete index specify the name of the index
db.movie.dropIndex("rating_1")


----to update data in mongodb
updateOne : this is used to update only one matching document
updateMany:this is used to update all matching document


updateMany({query},{update action})
updateOne({query},{update action})


what update operation
1. add new key-value pair--- $set, $min, $max
2. delete existing key------ $unset
3. overwrite the value of the key --- $set,$min, $max
4. increase or decrease the value of key --- $inc, $mul
5. to assign current date ---$currentDate
6. to rename the existing key ---$rename

If there is a array of values
1. add a new value array  $push---> $each, $position
2. delete a value from array  $pop,$pull
3. overwrite the value    $,$[],$[identifier]

upsert----either update or insert

replaceOne ----- to replace matching document with new Document
